# 🤝 Contribuindo com o Comanda Go!

Ficamos muito felizes que você queira contribuir com o projeto! Para manter o código limpo, organizado e agradável de trabalhar, siga os passos abaixo:

1. Faça um **Fork** do projeto.
2. Crie uma branch para a sua feature (`git checkout -b feature/nome-da-feature`).
3. Faça suas alterações e garanta que o código continua rodando perfeitamente em arquivo único (`app.py`).
4. Faça o Commit (`git commit -m 'Adicionando nova funcionalidade X'`).
5. Faça o Push para a sua branch (`git push origin feature/nome-da-feature`).
6. Abra um **Pull Request**.

Obrigado por ajudar a melhorar o Comanda Go! 🚀
