## 💡 Sobre o Projeto

O **Comanda Go!** é uma aplicação web ultraleve, desenvolvida em **arquivo único (Single-File)**, focada em dispositivos móveis e otimizada para o uso rápido com o polegar. É a ferramenta perfeita para pequenos comércios, lanchonetes, bares ou controle individual de mesas e comandas.

Tudo roda de forma fluida através de uma interface moderna utilizando **Tailwind CSS**, suporte completo a **Dark Mode** persistente, armazenamento local (`localStorage`), atalhos inteligentes de troco, gestão de produtos e fluxo de caixa simplificado.

---

## ✨ Funcionalidades

- 📱 **Mobile-First & UI Moderna:** Interface responsiva construída com Tailwind CSS e suporte a gestos (*swipe*).
- 🌙 **Dark Mode Persistente:** Alternância suave entre temas claro e escuro salva automaticamente no navegador.
- 🧾 **Gestão de Comandas:** Criação, edição, fechamento e controle de status de comandas em tempo real.
- 💰 **Calculadora de Troco Inteligente:** Atalhos rápidos para valores monetários para agilizar o atendimento no caixa.
- 📦 **Modal de Produtos:** Cadastro rápido e gerenciamento dinâmico de itens divididos por categorias.
- ⚡ **Single-File Architecture:** Todo o poder do Flask e front-end unificados em uma estrutura simples e de alta performance.

---

## 🛠️ Tecnologias Utilizadas

- **Back-end:** Python 3 + Flask
- **Front-end:** HTML5, JavaScript Vanilla, Tailwind CSS (via CDN)
- **Servidor de Produção:** Gunicorn
- **Hospedagem:** Compatível com Render, Railway, Fly.io, etc.
